# Loki

Loki is an independent fork of [Hermes Agent by Nous Research](https://github.com/NousResearch/hermes-agent), distributed under the MIT license with upstream attribution retained. The public command is `loki`; Loki uses its own configuration, runtime state and update source.

## Start with the source preview

Choose a release from [Loki releases](https://github.com/ObliviousOdin/loki/releases), read its notes, and follow the **[Installation guide](./getting-started/installation.md)** and **[Quickstart](./getting-started/quickstart.md)**.

The known published example is [0.1.0-alpha.1](https://github.com/ObliviousOdin/loki/releases/tag/v0.1.0-alpha.1), an **unsigned source preview** at commit `12690b426de4610916f91fb42f008391df550f27`. Its assets include source, installers and notice companions. It does **not** publish a native desktop application. Development candidates and later releases require their own build, installation and acceptance evidence; do not transfer alpha.1 results to them.

The [owned installation instructions](https://github.com/ObliviousOdin/loki/blob/main/docs/loki/INSTALL.md) and [delivery status](https://github.com/ObliviousOdin/loki/blob/main/docs/loki/PREVIEW-STATUS.md) define the measured scope. Do not install or update Loki through an upstream Hermes website, package, updater or signing identity.

## Configure your own provider

After installation, run `loki setup` and select a provider and model using a dedicated credential or your own configured local endpoint. Loki supplies no model subscription, OAuth application, hosted tool service or trial credits. Keep secrets in Loki's own profile; do not copy another agent's home or credentials.

See the [Quickstart](./getting-started/quickstart.md) for a conversation and resume check you can perform after configuration. Those checks require a working provider; source availability is not evidence of a completed conversation.

## Explore the inherited engine

The source retains the upstream runtime, tools, memory, skills, scheduling, delegation, messaging, provider integrations, TUI, desktop and web surfaces. This is inherited capability, not a claim that every service or packaged platform is qualified for Loki. Advanced reference pages may retain `Hermes`, internal module names, commands and upstream service examples. Use the public command `loki`, Loki-owned installation/update instructions and a separate Loki home; configure external services explicitly.

## For LLMs and coding agents

- **[`/llms.txt`](/llms.txt)** — curated documentation index.
- **[`/llms-full.txt`](/llms-full.txt)** — concatenated documentation, including inherited engine reference material.

With the configured `/loki/` site base, their public paths are `/loki/llms.txt` and `/loki/llms-full.txt`. They are generated locally before the English CI build. A build does not establish deployed availability. Apply the Loki installation and credential boundaries above when using either index.

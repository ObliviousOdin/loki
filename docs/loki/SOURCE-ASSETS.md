# Native preview source and notices

Every native preview release must include its exact Loki source archive, `LOKI-PREVIEW.json`, `SHA256SUMS`, `pilk-0.2.4.tar.gz`, `PILK-0.2.4-LICENSE.txt` and `PILK-SILK-CODEC-NOTICES.txt`. The metadata enumerates these required companions. Publish them alongside the unsigned native ZIP; do not offer the binary alone. Temporary Actions artifacts are not a substitute for the release assets.

Pilk 0.2.4 is a locked native codec dependency. Its source distribution declares GPLv3 and includes Skype Limited SILK codec copyright and redistribution conditions in its C/header sources. Loki retains the package license and the codec notice separately; the project and upstream MIT licenses and other bundled notices remain intact. These are recorded source/license facts, not a legal conclusion about a distribution.

`python scripts/loki/package_preview.py --commit <full-sha> --out <new-directory>` reads the admitted commit's `uv.lock`, downloads only its declared Pilk source URL, and verifies the exact SHA-256 and size before copying unmodified bytes. It checks the package license byte-for-byte and the codec comment with only line endings and trailing spaces normalized. `--pilk-source <file>` permits an existing archive only after the same verification. No source is extracted or executed. All release companions enter `SHA256SUMS`.

The Loki archive contains that exact commit's `uv.lock`, `pm/lock.json`, native packaging/assembly recipes under `scripts/bundles/` and `scripts/build/`, and the original notices. The normal native entry point is `python scripts/bundles/desktop.py --commit <full-sha> --variant bundled -- --publish never --mac zip`; use the source tree's preparation and identity gates. The source recipes record any build-path normalization and local ad hoc sealing used for that revision. A source archive and passing fixture tests do not establish reproducible binaries, signing trust or native qualification.

The app also retains Pilk's package license and codec notice under `Contents/Resources/licenses/pilk` on macOS (the equivalent resources directory on other packages). Final acceptance must verify these exact bytes, the source archive checksum, native provenance, privacy, relocation and the post-startup integrity seal before publication. Earlier local native artifacts remain superseded and must not be distributed.
